# 🍕 Pizza Sales Analysis Dashboard

## Project Overview

This project analyzes pizza sales data to uncover insights into customer behavior, product performance, revenue trends, and operational efficiency.

## Tools Used

* SQL
* Excel
* Power BI

## Business Questions

* What is the total revenue generated?
* Which pizza categories perform best?
* Which pizza sizes contribute the most revenue?
* What are the peak ordering hours?
* Which pizzas are best sellers and least sellers?

## Dashboard Features

### Executive Dashboard

* Total Revenue
* Total Orders
* Total Pizza Sold
* Average Order Value
* Day-wise Trend
* Hourly Trend
* Sales by Category
* Sales by Size
* Top 5 Best Sellers
* Bottom 5 Least Sellers

### Insights & Recommendations

* Key business findings
* Operational recommendations
* Product performance analysis

## Key Insights

1. Friday generated the highest sales and order volume.
2. Peak ordering hours occur between 11 AM–1 PM and 6 PM–9 PM.
3. Large pizzas contribute the highest share of revenue.
4. Classic pizzas generate the highest category revenue.
5. Sales are concentrated among a small number of top-performing products.

## Business Recommendations

* Increase staffing during Friday peak periods.
* Run promotions during low-demand hours.
* Focus marketing efforts on Large pizzas.
* Improve or review low-performing pizzas.
* Create combo offers using top-selling products.
